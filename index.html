Design and solve interlocking puzzles.

BurrTools finds assemblies for burr-type puzzles and analyses how they come apart move by move. You can build puzzles in different geometries, export them for 3D-printing and explore existing puzzles like Derek’s Dozen, shown on the right →

What it does

Create a puzzle with pieces, let the solver find every assembly, then watch the disassembler pull each one apart — level by level, move by move.

🖥️3D workbench

Powerful 2D and 3D piece editor and puzzle problem creator.

🎲Five grid types

Cubes, spheres, triangles, rhombic and tetra-octahedral — not just dice.

🧩Assembly solver

Finds all ways to fit your pieces into the target shape using multi-core SIMD powered search

🔓Disassembler

Proves each assembly can be taken apart and animates every move of the sequence.

🖨️3D-print export

Print-ready chamfered STL output for every grid, with preview and batch solution export.

📜Library & scripts

A C++ library, Python bindings and compressed XML files for your own tooling.

Five grids, not just cubes

Every puzzle is built on one space grid. The editor, solver and STL export all understand each of them; cubes and triangular prisms additionally disassemble move by move. Screenshots below are the BurrTools 0.8 editor with a bundled example per grid (click to enlarge):

🧊Cubes

The classic: six-piece burrs, Soma, packing puzzles. Shown: Derek’s Dozen result (269 voxels).

🔺Triangular prisms

Prisms on a triangle base, stacked in Z — hexagons included. Shown: Bermuda.

🔵Spheres

Tightly packed balls (stick to connected shapes). Shown: Stewart Coffin’s Ball Room.

🔷Rhombic

Cut-cube tetrahedra for rhombic-dodecahedral Coffin designs. Shown: Broken Sticks (384 voxels).

🔶Tetra-octa

Tetrahedra plus octahedra from the same cut cube. Shown: 4-Piece Tetrahedron.

How each grid behaves is documented under User guide → Shapes → Spacegrids.

9 Oct 2026

BurrTools 0.8.0 released

  • Multi-core solving plus a SIMD vector search core — up to 270× faster than 0.7.1, with identical results
  • Undo and redo across the whole editor, and a View Cube for snapping the 3D view around
  • Print-ready STL export with chamfered edges, batch export of all solution pieces, and an STL-accurate preview style
  • Python bindings, save/resume for long searches, check-for-updates, native file dialogs and menus
