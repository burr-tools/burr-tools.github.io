# What Came Next


Two chapters of the 2010 edition are gone from this revision because they
described software that did not exist: "Future Plans", a personal wish list,
and "Burr Design Tools", design automation that was explicitly written as if
already implemented.

For the record, several wishes from that 2010 list have since come true. The
solver gained faster SIMD search cores and parallel solving across all CPU
cores, disassembly runs concurrently on a thread pool, and STL export was
rebuilt around a chamfer mesher. Still open are ideas like a shape generator,
libraries of shapes to import from, better piece-colouring tools, and a debug
window that explains why an assembly fails. Those live on as GitHub issues,
and contributions are welcome at
`https://github.com/burr-tools/burr-tools`.
